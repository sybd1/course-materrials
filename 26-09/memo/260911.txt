CSS 선택자를 사용하는
요소를 선택
querySelector : CSS 선택자 문법 (#id, .class) 가장 먼저 조건에 맞는 첫번째 요소 1개만 가져온다.
querySelectorAll : CSS 선택자 문법 (#id, .class) 조건에 맞는 모든 요소를 찾아 정적 유사 배열(NodeList) 형태로 묶어준다.

getElementById : 오직 ID 이름 (header)만
getElementsByClassName : 오직 Class 이름 (btn)만. 여러 개. 살아있다??? 실시간 반영
