1. 01_event-handling: 이벤트가 발생했을때 실행할 함수
- 사용하지 않는 옛날 방법1: HTML 태그에 'onclick' 같은 어트리뷰트를 직접 작성하는 옛날 방식
<button onclick="alert('첫 번째 버튼 클릭!');">방법 1 버튼</button>

- 사용하지 않는 옛날 방법2: html 요소를 불러와서 .onclick 프로퍼티를 사용하는 방법. 나중에 대입한 함수가 이전 함수를 대체한다.

- 현대적인 표준 방법: 요소.addEventListener('이벤트종류', 실행할함수) 문법으로 사용한다. 하나의 이벤트에 다양한 이벤트 핸들러를 등록할 수 있다.


2. 02_event-object-and-this: 이벤트가 발생하면, 브라우저는 해당 이벤트의 모든 정보가 담긴 '이벤트 객체'를 생성한다.

- 일반 function 문법 함수 사용시 this는 현재 핸들러가 등록된 요소를 가르킨다. 매개변수.currentTarget 메서드도 동일한 요소를 가르킨다.

- 화살표 함수 안에서 this는 최상위 전역 객체 window를 가르킨다.

- e.target: 이벤트가 실제로 시작된 요소. 무었을 클릭했는가?
- e.currentTarget: 현재 이벤트 핸들러가 등록된 요소. 어디에 속해있는가?


3. 03_event-propagation
이벤트 버블링: 연못의 파문처럼

하위 요소에서 발생한 이벤트가 부모 요소를 따라 최상위까지 올라가는 '버블링' 현상

-'이벤트 전파' 순서
(1) 캡처링: window에서 이벤트 발생 요소 방향으로 내려감

(2) 타깃 단계: 실제 이벤트 대상에 도착

(3) 버블링 단계: 실제 이벤트 대상에서 부모 방향으로 올라감

5. 05_mouse-and-keyboard-events
마우스/키보드 이벤트
마우스 이벤트: 사용자의 마우스 움직임에 반응
- click: 눌렀다가 뗐을 때 발생
- mousedown: 마우스 버튼을 누르는 순간 발생
- mouseup: 뗐을 때
- mousemove: 움직일 때
- dblclick: 더블 클릭했을때
키보드 이벤트: 사용자의 키보드 입력에 반응
- keydown: 키를 누르는 순간 (누르고 있는 동안 계속 발생)
- keyup: 키에소 손을 떼는 순간
- 방금 누른 문자까지 반영된 최신 입력값을 처리해야 한다면 키보드 이벤트보다 input 이벤트가 더 적합하다.
