- 비동기 처리 방식
- setTimeout: 콜백함수를 예약을 걸어 원하는 시간에 실행시킬 수 있는 함수

</script>
- clearTimeout: 예약을 실행시키지 않는 함수?
- setInterval: 예약을 계속 반복해서 실행시키는 함수

- 비동기 처리 과정
 1) Call Stack: 자바스크립트 메인 엔진
 2) Web API: 브라우저
 3) Task Queue: 기다리고 있던 콜백함수가 Event Loop를 통해 Call Stack으로 보내진다.
 4) Event Loop: Call Stack이 비어있으면 Web API에게 받은 콜백 함수를 Call Stack에게 전달한다.
