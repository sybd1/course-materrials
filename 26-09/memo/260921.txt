useEffect: 화면 렌더링에 방해를 주지 않기 위해, 브라우저가 화면을 다 그린 직후 비동기적으로 외부 시스템과 소통합니다.
화면 진입 시 백엔드 REST API로 부터 데이터 불러오기, 브라우저 전역 Event 등록 및 해제, 실시간 채팅 연결 및 타이머 설정/해제

useMemo: Dependency Array (의존성 배열, 감시 대상 목록)의 값이 변하지 않았다면 무거운 CPU (중앙처리장치) 연산을 건너뛰고 이전 계산 결과를 재사용합니다. 수천~수만 건의 상품 목록 정렬, 복잡한 검색 필터링, 대시보드 통계 차트 데이터 가공. 자식 컴포넌트에 넘겨줄 무거운 객체/배열의 Reference Equality (참조 동일성, 메모리 주소 일치)를 유지하여 자식의 헛된 리렌더링 방지.

useCallback: 자바스크립트는 컴포넌트가 리렌더링될 때마다 내부 함수를 새 메모리 주소에 다시 만듭니다. useCallback은 이 함수의 생성 메모리 주소를 동결하여 고정합니다.
React.memo로 최적화된 자식 컴포넌트에게 이벤트 핸들러(예: onDelete, onClick)를 Props (프롭스, 부모 전달 속성)로 내려줄 때 필수 사용 (함수 주소가 안 바뀌어야 자식이 리렌더링을 안 함).
useEffect의 의존성 배열에 함수가 들어갈 때 발생하는 무한 루프 차단.

useRef: 렌더링 주기와 완전히 무관한 Mutable (가변성, 내부 값을 직접 수정 가능함) 객체 { current: 값 }을 제공합니다. 값을 아무리 바꿔도 컴포넌트가 다시 그려지지 않습니다.
실제 브라우저 DOM 요소를 직접 조작할 때 (예: 모달창이 열리자마자 검색창에 포커스 주기 inputRef.current.focus(), 비디오 재생/정지).
화면에는 안 보이지만 컴포넌트 내부에서 계속 기억해야 하는 값 (예: setInterval의 타이머 식별 번호 저장, 이전 State 값 추적).




State: 화면에 출력되고 변경 즉시 UI가 달라져야 하는 값.
Ref: 렌더링 사이에 기억해야 하지만, 변경만으로 리렌더링 할 필요가 없는 값을 저장 ex) input 포커스, 스크롤 이동, 실제 DOM 요소 기능을 호출할 때


custom Hook : 컴포넌트 이름만들때 소문자 use로 시작
