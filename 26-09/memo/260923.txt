라우팅 : 주소창의 경로를 보고 어떤 화면을 켤지 고르는 거야. /면 홈, /login이면 로그인. React에선 페이지를 새로 받는 게 아니라, URL만 보고 컴포넌트를 갈아끼워.

매핑: 라우팅은 “주소 → 화면”, 매핑은 “데이터 → 다른 데이터”(또는 리스트 → JSX 목록).

렌더링: 그려질 내용을 계산하는 것.
React 기준으로는 컴포넌트 함수가 다시 돌고, Virtual DOM을 만들고, 실제 DOM을 어디를 고칠지 정하는 단계. “화면에 픽셀이 찍혔다”와는 아직 다를 수 있어.

페인팅: 브라우저가 픽셀을 칠하는 단계. 레이아웃으로 박스 위치/크기를 잡은 다음, 색·글자·이미지를 레이어에 실제로 찍는다. 그다음 GPU가 그 레이어들을 합성해서 모니터에 보낸다.

'use client' 선언을 해야 사용할 수 있다.

usePathname() : 현재 URL의 순수경로를 읽어옴(활성탭/ 메뉴 스타일 적용 시)

useParams() : [폴더명] 형태의 동적 라우팅 파라미터를 읽어옴 (상세 페이지 데이터 페칭 시 /menu/1에서 1)

useSearchParams() : URL 끝의 쿼리스트링(?key=value)을 읽어옴. (검색 결과 페이지, 필터링 시 ?menuName=마늘)

useRouter() : 함수/이벤트 내에서 프로그래밍 방식으로 페이지 이동 (폼 제출 후 완료 페이지 이동, 뒤로 가기 등 router.push())
