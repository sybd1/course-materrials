- zustand (독일어로 상태라는 뜻)
전역 상태 (Global State)를 관리하는 라이브러리 중 하나.
store를 컴포넌트 밖에 따로 두고 끌어와서 언제든지 사용할 수 있다? 상태관리 하기 편리한 라이브러리. store는 외부의 공용창고라고 생각하면 된다.

zustand는 store에 state값들을 저장해둬 사용하지 않는 중간 경로의 컴포넌트에게 따로 state 값을 지정해두지 않아도 된다.

npm install zustand : zustand 설치 명령어
src 하위 폴더로 store 만들어서 사용
create라는 함수 이용. 파라미터로 set

실무에서는 store의 역할을 분리해서 만든다.

middleware: 기존 동작 중간에 추가 기능이 생긴다.
