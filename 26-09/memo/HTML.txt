 - 태그 목록
<h1></h1> 숫자가 클수록 글자 크기가 커지는 제목 태그
ctrl + / = <!-- --> 화면에 보이지 않는 주석 태그
<hr> 시각적 구분선 태그
<p></p> 문단 분리 태그. 완결된 하나의 생각이나 문맥 단위를 묶을 때
<br> 단순 줄바꿈 태그. 같은 문단 안에서 단순 줄을 바꿀 때
<pre></pre> 쓰는 그대로 표현하는 태그
<b></b> 모양만 굵은 글씨 태그 =/<strong></strong> 웹페이지를 읽을때 의미까지 강해진다. 음성이 도드라진다던지. 
<i></i> 단순 기울인 글씨 <em></em> 강조하는 기울인 글씨
<mark></mark> 형관펜 태그
<del></del> 삭제된 내용 표시하는 태그. 글씨 가운데 줄 그어져 있음.

tr (Table Row) : 가로 행을 만든다.
th (Table Header) : 행의 제목 셀을 만든다. 굵은 글씨 가운데 정렬 자동 적용.
td (Table Data) : 일반 셀을 만든다. 보통 굵기에 왼쪽 정령로 표시.

마크업 마크다운 정확한 의미 기능
table 이후 어떤 태그? caption으로 시트 제목. thead or tbody로 표 상단 및 하단 구성
tr로 행 하나 만들고 th,td로 글자 채우기
form 다음 fieldset 이후 legend로 폼 상단 제목 만들기
radio로 체크박스 만드는 기능은 input 태그의 type속성의 속성값이다. 그 이후 id, name, value까지 작성
input 안의 type은 속성값이 정해져있다. ex) text, pw
button 태그 다음은 속성 type을 입력하고 속성값 submit과 reset이 있다.
