JavaScript

변수 : 데이터를 담아두는 저장소
자료형 : 데이터가 문자? 숫자? 참/거짓? 구분하는 기준

연산자 : 산술, 할당, 증감 연산자 등이 있다.
산술연산자 : (+, -, *, /, %, **)
할당연산자 : (+=, -=...)
증감연산자 : ++ 1증가, --1 감소 후위증감, 전위증감이 있다.
 - 후위증감 : (a++, a--) 다음 값을 증가 시킨다.
 - 전위증감 : (++a, --a) 값을 먼저 바꾸고, 바뀐 값을 사용한다.

동등/일치 비교 연산자 
동등 비교 : (==, !=) 연산자는 먼저 암묵적 타입 변환은 통해 타입을 일치시킨 후 비교
일치 비교 : (===, !==) 연산자는 타입과 값이 모두 일치하는지 비교
비교할땐 대체로 엄밀하게 하기 위하여 일치 연산자를 사용한다.

비교연산자 : 좌항과 우항의 비교 연산자를 비교하고 그 결과를 불리언 값으로 변환한다.
if나 for문과 같은 제어문의 조건식에서 주로 사용한다.

논리연산자는 AND, OR, NOT 연산자가 있다.
단축평가 : 표현식을 평가하는 도중 평가 결과가 확정 된 경우 나머지 평과 과정을 생략하는 것
논리 AND (&&) a와 b 모두 true일 때만 true
논리 OR (||) a또는 b 중 하나만 true이면 true
논리 NOT (!) ???

삼항연산자 : 조건식에 따라 두 값 중 하나를 선택하는 연산자
키워드 변수명 = (조건) ? "값1" : "값2";
const age = 20;
const result = (age >= 20) ? "성인" : "미성년자";
