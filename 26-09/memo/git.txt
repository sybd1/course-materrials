git 명령어

<git config user.name "sybd1"> 이름 선언.
<git config user.email "gjffpdlem@email.com"> 이메일 선언.
<git init> 작업 공간 선언.
<git status> 현재 상태 확인. 
>modifiled = 상태 변경되었다는 뜻.
<git add .> 모든 상태 등록 Work space(or Working directory) 에서 Staging area(임시공간)로 등록
> Work space(or Working directory) : 추적 되지 않는 상태.
> Staging area : 추적되는 임시공간의 상태.
<git commit -m '내용'> commit = 변경 이력 저장, 버전 관리를 통해 생성 된 파일.
<git log> commit 된 파일 기록 확인
<git log --oneline> log파일 기록 간단하게 확인

git 파일 저장 기본 순서
git add -> git commit -> 파일 변경 및 수정 -> git add -> git commit

<git revert _______> 실수로 변경한 사항 다시 되돌아가서 저장. _______ -> hash
CLI 편집기가 떴을때 <wq> 저장하고 종료한다는 뜻
<git branch -M main> 마스터를 브랜치를 메인 브랜치로 바꾸는 명령어.
<git remote add ogrigin https://github.com/sybd1/git-practice-kmg.git> 원격 저장소 등록하는 명령어.
> origin : 관례상 붙이는 저장소 이름
<git remote -v> 원격 저장소 경로 확인 명령어.
<git push -u origin main> 로컬에 저장된 커밋 원격저장소로 푸시. 오리진이라는 메인 브랜치로 푸시한다는 뜻
> -u (upstream)
<git pull origin main> 원격저장소에서 로컬로 당겨오는 명령어.
<git branch feature/greeting> 브랜치를 만드는 명령어.
> feature/greeting : 통상적으로 사용하는 서브(기능) 브랜치 이름.
<git branch> 현재 branch log 확인
<git switch feature/greeting> main에서 feature/greeting로 브랜치 변경.
<git merge feature/greeting> feature/greeting을 main 으로 병합.
<git switch -c feature/conflict> feature/conflict 라는 브랜치를 만들어 
-c 브랜치 이동까지 하겠다는 명령문

conflict 충돌 : 충돌시 쓸모없는 문자 다 지우고 수정 및 추가.

PR (Pull Requests) : 서브 브랜치에서 메인으로 당겨오기 요청
Fork : 상대방 레파지토리 내 레파지토리로 가져오기. 오픈소스 긁어오기.

<git clone 주소> 원격저장소에서 내 로컬 폴더에 새롭게 생성.

git remote set-url origin <새로운_GitHub_저장소_URL> : 원래 있던 remote repository 지우고 새로운 remote repositorys

# 1. 원격 최신 기록을 가져옴 (로컬 파일은 변경하지 않음)
git fetch origin

# 2. 로컬 main 브랜치를 원격 main과 완전히 똑같은 시점으로 강제 리셋
git reset --hard origin/main
