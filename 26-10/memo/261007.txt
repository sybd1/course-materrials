Java에서 **class(클래스)**는 데이터와 그 데이터를 다루는 메서드(method, 특정 작업을 하는 명령 묶음)를 하나로 묶어 둔 설계도입니다. new로 그 설계도를 실행하면 메모리에 실제 객체가 생기고, 그 객체를 **instance(인스턴스)**라고 부릅니다.

API : 자바에서 제공해주는 기능이며 찾아와 사용할 대상이다. 자바는 자주 필요한 기능을 클래스와 메소드로 미리 제공한다. 이런 기능을 사용하기 위한 규칙과 도구의 집합을 API라고 부른다. 


java.lang pakage에 있는 메소드는 import하지 않아도 사용가능하다. 모든 java.lang 메소드는 static 메소드이다.

Scanner: java.util 안에 있는 클래스이다. java가 제공하는 api. import 해줘야 사용 가능하다. 사용자의 입력 정보를 분석한다.

Scanner 객체 생성 후, java가 제공하는 메소드를 사용해 기능을 이용할 수 있다.

Scanner 메소드
- nextLine(): 엔터 키 이전까지 한 줄 전체를 문자열로 읽음.
- next(): 공백 문자나 개행 문자 전 까지를 문자열로 읽음.
- nextInt(): 공백 이전까지의 정수 값을 읽음.
- nextDouble(): 공백 이전까지의 실수 값을 읽음.

\n은 버퍼에 남아 있어서 오류가 날 수 있다. 개행문자 처리를 해야 제대로 된 문자값을 받을 수 있다.


Integer 클래스를 사용하면 자료형 값을 받아 다른 자료형으로 사용할 수 있다.

stack, heap : new라는 객체를 만들면 Heap에 저장된다. 변수를 선언한 참조변수는 Stack에 저장되고, Heap의 주소값을 참조한다.

배열도 Heap에 생성된 배열을 Stack에서 Heap의 배열 주소값을 참조해서 사용한다.
객체 생성시 좌항의 변수가 Stack에 존재하고, 우항의 new로 생성된 배열이 Heap에 존재한다.


dimensional 다차원 배열
int arr[][] = new int [행][열];


A라는 배열 변수를 B라는 변수에 집어 넣으면, Heap에 저장된 같은 참조값을 복사해서 사용할 수 있다. A와 B 같은 배열을 참조하고 있다.

얕은 복사: B라는 변수에서 배열의 값을 변경하면 원본 A 배열도 값이 바뀐다.

깊은 복사: 원본에 영향을 주지 않는다. 2차원 배열이나, 객체나 참조값을 가지고 있는 배열은 얕은 복사가 일어날 수도 있다.

배열 안의 값이 참조형인지 아닌지 주의하기.
