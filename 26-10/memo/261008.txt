향상된 for문 안에서의 변수는 임시적인 지역 변수이다. 조회하면서 값을 바꿀 수 있지만 원본 배열은 바뀌지 않는다. 조회 하는 목적으로 사용한다.

필드: 클래스 내부에 선언하는 객체의 상태(데이터) 또는 클래스가 관리하는 데이터를 나타내는 변수. 

필드(Field)는 클래스 내부에 선언되어 객체 또는 클래스가 관리하는 데이터를 나타내는 변수이다. 객체가 가져야 할 데이터는 인스턴스 필드로 선언하여 관리한다.

외부에서 참조연산자로 필드 값을 불러와서 아무 값이나 집어 넣으면 변경된다. 그래서 외부에서 값을 함부로 변경하지 못하게 막아주는 규칙을 설정해야한다. = Capsulation 캡슐화

Capsulation 캡슐화
접근제어자로 필드를 관리한다.
(+) public: 모든 패키지에서 접근 허용
(#) protected: 동일 패키지에서 접근 허용 (단, 상속관계에 있는 경우 다른 패키지에서도 접근 가능)
(~) default: 동일 패키지 내에서만 접근 허용 (작성하지 않는 것이 default)
(-) private: 해당 클래스 내부에서만 접근 허용

[Getter / Setter 메소드]
Getter (접근자): 내부 필드의 값을 외부에 반환하는 메소드
Setter (변경자): 외부에서 전달된 값을 받아, 내부 필드의 값을 설정 또는 변경하는 역할

DTO (Data Transfer Object) : 행동은 없고 데이터만 있는 객체. 데이터를 포장해서 여러 계층에 안전하게 나르는 상자. 관련값들을 옮기는 상자라고 생각.
DTO 규칙: 필드는 무조건 private
