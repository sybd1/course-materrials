- 상속 : 부모와 자식관계의 클래스.
여러 개의 클래스의 공통정보와 개별 정보를 구분하여 공통정보는 부모가 자식에게 나눠주고, 자식들은 개별 정보를 담고 있다.
부모 클래스에 공통 정보
자식 클래스에 각각 특징이 있는 개별 정보

공통 기능을 가진 여러 클래스의 관계를 표현할 때 선택적으로 사용.

개념적으로 "IS-A" 관계가 성립해야 부모 자식의 관계가 잘 성립할 수 있다.
IS-A 관계가 잘 성립하지 않는데, 상속을 하면 이후에 수정할 때 더욱 복잡해질 수 있다.

protected: 같은 패키지에서 접근할 수 있으며, 다른 패키지에서는 상속받은 자식 클래스가 사용할 수 있다.

"extends" 부모에게 상속 받는 문법
"접근제한자 클래스 자식(하위)클래스 extends 부모(상위)클래스 {}"


한번에 하나의 클래스만 상속받을 수 있다.



- super()
부모 클래스의 생성자를 호출할 수 있는 코드.

"super()" 부모 클래스의 기본 생성자를 호출. 자식 클래스 생성자를 호출하는 내부에서 부모 클래스를 호출한다. 그러나 자바 컴파일러가 자동으로 호출해주므로 "super()"를 굳이 적을 필요가 없다.
"super.메서드" 부모의 메서드 호출하는 문법


- Overriding

- 오버라이딩 (@Override): 부모에게 물려받은 메서드를 자식의 목적에 맞게 같은 형태로 다시 작성하는 것.
오버로딩과 다르다.

부모에게 물려받은 메서드는 "접근제한자 반환값 메서드명" 동일하게 적은 뒤에 확장할 수 있다.

@: 어노테이션이라고 부른다.
@Override: 컴파일러가 부모 메서드를 올바르게 재정의 했는지 검사한다.

규칙
부모의 메서드 선언부(접근제한자, 반환형, 메서드이름, 매개변수) 값이 같아야한다. 매개변수 값이 다르면 오버라이딩은 불가능해도, 오버로딩은 가능할 수 있다.
private 메서드: 선언한 클래스 내부에서만 사용할 수 있으므로 오버라이딩 불가
final 메서드: 재정의(오버라이딩) 금지, 호출은 가능.
protected 메서드: 접근제한자를 public으로 바꿀 수 있다.
자식 클래스가 부모 범위보다 더 넓은 범위로 오버라이딩하는 것은 허용된다. 더 좁은 범위로 오버라이딩 하는 것은 불가능하다.


다형성의 개념을 제대로 알기 위해 상속을 배운 것이다.


- 다형성 (polymorphism)
부모 타입으로 여러 자식 객체를 다룰 수 있다.
같은 메서드를 호출해도 실제 객체에 따라 다른 동작이 실행되는 성질이다.
업캐스팅 - 자식 객체의 참조값을 부모 타입 변수에 저장. 
자식을 부모 타입에게 담을 수 있다.

부모타입 변수 = new 자식클래스();

업캐스팅: 자식 객체의 참조값을 부모 타입 변수에 저장
다운캐스팅: 자식 고유 멤버 사용시 사용한다. if문과 instanceof 메서드 활용해서 안전하게 확인.

동적 바인딩 - 컴파일 시점에는 부모의 메서드를 가리키다가, 실행(Runtime)될 땐 자식을 가리키는 동작.


- 추상 클래스 (abstract class)
"abstract" 키워드로 선언
"public abstract class Player {}"
일반 메서드와 추상 메서드를 모두 가질 수 있다.
추상 메서드는 몸체가 없으며, 자식 클래스에서 반드시 오버라이딩 해야한다.
"public abstract void attack();"
참조변수 타입으로는 사용할 수 있다. - 다형성 적용 가능



- 인터페이스 (interface)
일반적으로 인터페이스 안에는 몸통이 없는 추상 메서드를 작성해야한다.
인터페이스 안에서 추상 메서드를 작성할 때는 "public abstract"를 생략해도 자동으로 적용된다.
"implements" 인터페이스를 구현할 때 사용하는 키워드.
인터페이스를 구현하려면 추상메서드를 오버라이딩 해야한다.


추상 클래스  / 인터페이스
abstract class / interface
extends / impements
직접 객체 생성X / 직접 객체 생성X
인스턴스 필드 O / 인스턴스 필드 X (특별하게 사용 할 수도 있다.)
부모 클래스 하나만 상속 / 여러 인터페이스 구현 가능
공통 상태와 기반 구현을 가진 계층 / 여러 클래스가 지킬 기능 규격 역할
다형성 적용 가능 / 다형성 적용 가능
