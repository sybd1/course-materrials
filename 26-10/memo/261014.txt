1. API
프로그램을 만들 때 사용할 수 있도록 미리 제공되는 클래스와 메소드의 사용 규칙.
Java에서 제공해주는 API에 관하여 배운다. 유용한 것 위주.
객체 관련 API

- Object
자바 객체들의 최상위 부모는 Object이다.
extends 상속하지 않아도 모든 클래스는 Object의 자식이다.


Object.toString() 메서드
원래는 클래스명과 16진수 형태의 해시값을 보여주는 형태이지만, 객체의 필드값을 보여주도록 오버라이딩(재정의)해준다. 자바가 객체를 문자열로 변경하기 위해 .toString()를 호출한다.

Object.equals() 메서드, Object.hashCode() 메서드
각각의 객체끼리 동일성비교 (==)를 하면 Heap안에서 각각의 주소값을 비교하기 때문에 각각의 객체는 내용이 동일해도 같은 값이 아니다. 동등성비교 (equals())도 같은 원리로 비교하기 때문에 같은 값이 아니다.

내용이 똑같은 각각의 객체를 동등한 주소를 바라보게 만들어야 할 때가 있어서 사용하는기능이다. equals() 메서드를 오버라이딩해서 활용한다. 

hashCode() 메서드
equals가 true를 반환하면, hash값도 true여야 equals가 동등하게 만드는 기능이 제대로 작동한다. 이중으로 검사하고 반환하는 것 같다.


- String

trim(): 문자열 앞/뒤 공백제거
toUpperCase() / toLowerCase: 대/소문자 변환
indexOf(): 특정 문자/문자열의 처음 위치(인덱스) 반환. 찾지 못하면 -1 반환.
substring(시작 인덱스, 끝 인덱스): 문자열의 특정 구간을 잘라내어 새로운 문자열로 반환. 시작지점부터 끝의 전까지 불러온다.
replace(): 문자열 내의 특정 문자/문자열을 다른 문자/문자열로 치환한 새로운 문자/문자열 반환
delete (start, end): 시작 인덱스부터 종료 인덱스 전까지의 문자열 제거
insert(index, value): 지정한 인덱스에 값 삽입
reverse(): 문자열의 순서를 뒤집는다


split(): 특정 구분자를 기준으로 문자열을 잘라 '문자열 배열'로 반환한다.
자바의 split()은 구분자를 정규식으로 해석한다.

[이스케이프 문자] 
문자열 내에서 줄바꿈, 탭, 따옴표 등 특별한 기능을 하는 문자, 역슬래시(\)로 시작한다.
split() 구분자: \n (줄바꿈), \t (탭), \" (쌍따옴표), \' (홀따옴표), \\ (역슬래시)

isEmpty(): 문자열의 길이가 0이면 true, 아니면 false 반환


리터럴 객체: String str = "java";
new 생성자: String str = new String("java");
리터럴 객체는 JVM의 String Constant Pool 이라는 곳에 보관한다.
리터럴 객체로 만든 같은 내용의 값은 JVM이 같은 값이 있는지 String Constant Pool에서 찾아보고 같은 값이 있다면 재사용한다.
new로 만든 객체는 Heap 영역에서 새롭게 만들어지고 각각의 객체와 주소값을 가진다.

String 이라는 자료형의 클래스가 Object에 상속되어 있기 때문에, 문자열 비교는 이미 동등비교를 할 수 있는 기능이 Object에 오버라이딩 되어있다. 그래서 문자열 비교는 equals를 사용하는 것이 안전하다.

문자열 비교는 equals() 메서드 사용.


null에 안전한 문자열 비교
equals() 메서드는 좌항의 값 먼저 호출하고 그 뒤에 우항의 값을 불러와 비교한다.

문자열은 불변(immutable) 객체이다.
원본 문자열에 새로운 문자열을 더하면, 원본 문자열 객체가 수정되는 것이 아니라, 완전히 새로운 객체를 생성한다. 그리고 원본 문자열 객체는 새 문자열을 가리키게 된다.


- StringBuilder 객체
불변의 새로운 문자열 객체를 계속 생성하지 않고 가변적으로 사용하는 방법.
append()로 내부 내용을 누적한다. 반복적인 문자열 조립에 적합하다.

append()는 자기 자신(StringBuilder)을 반환하므로 메서드 체이닝이 가능하다.
메서드 체이닝: 반복적으로 메서드를 사용할 수 있는 문법



보통 사용자에게 전달받는 숫자는 문자열로 받게 된다.


- wrapper 클래스
기본 자료형의 값을 객체 형태로 감싸는 클래스. int와 char를 제외하고 모두 앞글자가 대문자로 바뀐다.

문자열로 된 숫자를 숫자열로 변환해 계산할 수 있게 되는 기능.
문자열 -> 숫자

크기를 정하면 변경할 수 없는 유연하지 못한 배열 대신 사용할 수 있는 기능.

문자열로 된 숫자만 가능하다?

기본타입 / 래퍼 클래스
int -> Integer: boxing
Integer -> int: unboxing
자바에서 기본적으로 박싱, 언박싱을 잘해준다.

Wrapper 객체는 null값을 가질 수 있지만, 기본 자료형은 null 값을 들고 있을 수 없기 때문에 null 값을 담은 wrapper 클래스를 언박싱 하려고 하면, NullPointerException이 발생한다.

Wrapper는 객체이므로 값 비교에 equals()를 사용한다.

숫자 -> 문자열
String.valueOf(값)



- time

문자열은 화면에 출력하기는 편하지만, 날짜나 시간 같은 계산하는 것은 문자열로 하기에 불편하다. 그래서 자바가 날짜, 시간을 편하게 계산할 수 있게 해주는 API를 제공한다.

LocalDate: 날짜
LocalTime: 시간
LocalDateTime: 날짜 + 시간
LocalDateTime.now(): 현재시각

java.time 객체는 불변이다.
시간을 계산해도 원본에서 계산한 새로운 객체를 반환한다. 그래서 새로운 반환 값을 변수에 저장해야 계산 결과를 사용할 수 있다.

포매팅
특정 형식의 문자열을 날짜/시간 객체로 변환할 수 있다.


2. generic
generic: 데이터의 타입을 일반화한다라는 의미.

클래스나 메서드에 사용할 자료형을 미리 정하지 않고, 객체를 만드는 시점에 자료형을 정할 수 있다.

타입별 중복 코드룰 줄이고, 잘못된 타입의 데이터가 들어오는 것을 방지한다.

제네릭을 사용하지 않고 자료형을 Object로 사용한 경우.
자료형은 Object로 선언하고 기본 자료형들을 모두 불러올 수도 있다. 컴파일 시점에는 오류가 발생하지는 않지만, Runtime(실행) 시점에는 치명적인 'ClassCastException' 오류가 발생한다.

문법
다이아몬드 연산자 <> 를 사용한다.

생성자를 만들때 자료형뒤에 <기본자료형>을 붙여주고, new 클래스 뒤에도 <>를 붙여줘야한다.
생성자를 만들때 타입을 무조건 지정해줘야한다.

<> 안에 타입변수로서 지정받는 값은 Wrapper 클래스의 객체로 지정해야한다. 일반 자료형은 들어올 수 없다. 참조 자료형을 사용한다.
