- LinkedList
List 내부의 ArrayList는 배열처럼 번호가 붙은 칸으로 값을 관리한다. LinkedList는 각각의 데이터 요소가 있고, 이전링크 주소와 다음 링크 주소를 담고 있다. 그 요소가 기차처럼 이어져있다. ArrayList의 경우 중간에 값을 추가하거나 삭제할 경우 번호가 밀리거나 당겨져서 비효율적으로 동작할 수 있다. 그래서 조회할때 유리하다. LinkedList는 요소마다 앞 뒤의 주소를 가지고 있어서 중간에 요소를 추가하거나 삭제해도 요소끼리 주소만 참고하기 때문에 순서가 밀리거나 당겨지는 경우가 없어서 추가 삭제할때 효율적인 정렬이다.

LinkedList는 '이중 연결 리스트' 방식으로 데이터 관리. 각 요소는 자신의 앞/뒤 요소만 기억한다.

**자료 구조 특성에 맞게 "Collection 인터페이스를 상속한 List 인터페이스의 구현 클래스인 ArrayList와 LinkedList를 사용해야한다."**

ArrayList는 특정 순서의 값을 조회 할 때 효율적이다.
LinkedList는 중간에 데이터 추가/삭제에 효율적이다.
추가/삭제가 많다는 이유만으로 항상 ArrayList보다 빠른 것은 아니다. 현업에선 대체로 ArrayList를 사용할 일이 많다.

- Deque 하위 클래스
Queue의 하위 클래스 Deque는 원래 양방향에서 값을 자유롭게 꺼내 사용하지만, 한쪽을 막고 Stack처럼 후입선출로 사용하는 편이다.

1,2,3,4,5 순서대로 값을 넣으면 5,4,3,2,1을 반환한다.

push(): 맨 앞에 값을 추가.
peek(): 마지막에 쌓은 데이터 확인.
pop(): 가장 꼭대기 요소를 '꺼내'고 제거한다.

- Queue 인터페이스 (FIFO) 방식 자료구조.
Queue 인터페이스는 데이터 선입선출. 마치 양방향이 뚫린 파이프에 한 방향으로 데이터를 넣고, 반대 방향에서 데이터를 꺼낸다. 선입선출.

offer(): 기존 대기열 맨 뒤에 값을 추가
peek(): 맨 앞의 요소를 '확인'
poll(): 맨 앞의 요소를 '꺼내고' 제거한다.

queue는 값이 비어있는 경우 null을 반환한다.
Deque는 값이 비어있는 경우 NoSuchElementException 오류를 일으킨다.

2. Set 인터페이스
Set은 몇번째 값을 꺼낸다는 순번 개념 자체가 없음. 데이터가 마구잡이로 들어있어서 중복된 값을 허용하지 않는다.

- HashSet(): Set 인터페이스의 구현 클래스
순번 개념 없이 저장하고 기억한다.

iterator()를 호출하면 컬렉션을 순회할 수 있는 Iterator 객체를 반환한다.
hasNext(): 다음에 꺼낼 요소가 있다면 true
next(): 다음 요소를 꺼냄

- linkedHashSet(): Set인터페이스의 구현 클래스
중복되지 않은 값을 입력된 순서로 기억해준다.

-TreeSet(): Set 하위 클래스의 SortedSet의 구현클래스. 중복 불가 특징과 함께, 요소를 저장할 때마다 비교 기준에 따라 요소를 정렬해서 보관.
String 클래스와 Integer 같은 클래스는 이미 Comparable을 구현하여 자동 정렬된다.



3. Map 인터페이스
Collection Framwork안에 속하지만, Collection의 하위(자식) 클래스는 아니다.
Entry = key, value를 하나의 쌍으로 묶어서 관리
ket는 중복 저장을 허용하지 않는다.
value를 중복 저장을 허용한다.

HashMap(key, value): Map의 구현 클래스. 저장순서를 유지하지 않는다.

존재하지 않는 key 값은 null을 반환한다.

containsKey(): key 존재 여부 확인
keySet(): 모든 키를 Set으로 받아, 카로 값을 다시 조회한다.
values(): 모든 값들만 Collection으로 반환 받아 순회하는 방법
entrySet(): 모든 키-값 쌍(Entry)를 Set으로 반환한다. key와 value 모두 필요할 때는 key로 다시 조회하지 않는 이 방식이 가장 직접적이다.




Lsit: 순서O, 중복O, Stack LIFO, Queue FIFO
Set: 순서X, 중복X, HashSet, LinkedHashSet: 순서 유지, TreeSet: 비교기준에 따라 정렬
Map: key-value, key는 중복X value 중복O,
