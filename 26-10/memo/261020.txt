데이터베이스 (Database) : 데이터를 저장하고 관리하는 공간
컬럼 (Column) : 열. 각 데이터가 어떤 항목인지 나타냄
로우 (Row) : 행. 하나의 데이터 기록
테이블 (Table): 데이터를 행과 열로 정리한 표

3. 기본 문법

- SELECT xyz FROM xyz; : 단일 열 (컬럼) 데이터 검색.

콤마를 이용해 여러 열의 데이터 함께 검색할 수 있다.
모든 열에서 데이터 검색(*: 모든 컬럼을 의미하는 와일드 카드)

SELECT로 간단한 연산과 함수를 계산하는 컬럼을 만들 수 있다.
SELECT 6 + 3;
SELECT NOW; 현재 시간
SELECT CONCAT('홍','길동');
SELECT CONCAT('홍','길동') AS name;


- ORDER BY : SELECT문의 가장 마지막에 위치하며, 결과 집합을 하나의 열로 정렬

원하는 열을 선택해 오름차순으로 정렬해준다.
원래는 ORDER BY 로 정리 하려는 구문 뒤에 ASC가 오름차순을 의미하지만, ASC는 생략가능하다.

내림차순은 DESC를 붙여준다. 생략 불가능하다.

ORDER BY 도 뒤에 콤마를 붙여서 중복되는 값들을 n차 기준을 설정해 정렬할 수 있다.

- 연산 결과로 정렬
SELECT로 불러온 것(?)들을 연산하고 AS로 결과값 별칭을 붙여주고 FROM으로 가져와, ORDER BY로 별칭을 불러 정렬할 수 있다.

- FIELD(컬럼 첫번째, 두번째, ...) : 컬럼 값이 목록의 몇 번째에 있는지 숫자로 알려준다.
SELECT FIELD()

ORDER BY
	FIELD(orderable_status, 'N', 'Y');
N을 1순위로 Y를 2순위로 지정

-  IS NULL 으로 NULL 이면 true = 1, false = 0을 이용해서 정렬할 수 있다. null이 아닌 값들은 false니까 위로 올라가고, null은 true이기 때문에 아래로 내려간다. 1과 0 순위 차이. 

- WHERE 조건 필터링의 역할
비교 연산자 활용 (=, <>, > <=)
<>는 != 같은 연산자다.
논리 연산자(AND, OR)를 활용
AND (두 조건이 모두 참이어야 함)
OR (둘 중 하나라도 참이면 참)
WHERE / AND, OR 사용해서 2가지의 값을 가지고 올 수 있다.
AND, OR 이 함께 사용되면 AND가 먼저 실행되고, OR이 실행된다.
JAVA에서 했던 것처럼 소괄호를 사용해 우선순위를 정할 수 있다.
BETWEEN / AND : 해당 사이의 값.
NOT은 부정을 붙인다.
EX) NOT BETWEEN 10000 AND 25000;

LIKE 특정 값을 찾고 싶을 때, 부정은 NOT LIKE
%는 문자가 없거나 여러 개 있어도 된다는 와일드 카드이다.
'%이름%' : 이름이라는 문자가 어느 사이에 있어도 다 찾아온다.
'%이름' , '이름%' : 마늘로 끝나는 메뉴, 마늘로 시작하는 메뉴

IN 연산자, 부정은 NOT IN
포함되는 값들을 가지고 온다
IN (4, 5, 6)

IS NULL 연산자


- DISTINCT (중복 제거)
중복된 값을 제거하고 고유한 값들의 목록만 보고 싶을때 사용
SELECT DISTINCT ~~~
없애고 싶은 칼럼 앞에 DISTINCT를 붙인다.

열이 여러 개인 DISTINCT
지정된 모든 열의 조합이 똑같을 때만 중복으로 간주하여 제거


- LIMIT 개수
결과중에 딱 내가 원하는 만큼만 잘라서 줘!! 라고 요청하는 키워드.
원하는 정렬을 한 뒤에 LIMIT 개수를 하면 상위부터 잘라준다.

LIMIT [시작 위치(건너뛸 개수)], [가져올 행의 개수]



- JOIN
각 테이블의 행을 연결해서 한 결과에서 볼 수 있는 기능.
테이블 별칭을 붙이는 건 JOIN 구문에서 필수이다.
As로 컬럼과 테이블에 별칭을 붙일 수 있다.
띄어쓰기가 있으면 따옴표 사용. 없으면 생략 가능

테이블에 붙인 별칭이 a 라면 칼럼 앞에 a.칼럼으로 명시적으로 표현해줘야한다.
테이블 별칭은 겉으로 표시가 되는 것은 아니다.

INNER JOIN : 교집합 (가장 기본적인 조인)

SELECT
	a.menu_name,
    b.category_name
FROM
	tbl_menu a
JOIN tbl_category b ON a.category_code = b.category_code;

메뉴 테이블(기준 테이블)에 있는 카테고리 코드와, 카테고리 테이블(조인 테이블)에 있는 카테고리 코드를 찾아서 각각의 이름을 연결 시켜 주었다.
ON : 같은 행을 찾을 연결 조건

OUTER JOIN(LEFT / RIGHT)
-- LEFT JOIN : JOIN 구문을 기준으로 왼쪽 테이블의 데이터는 모두 보여주고, 오른쪽 테이블에서 짝이 맞는 데이터가 없으면 'NULL'로 채워서 보여준다.

FROM 절(왼쪽 테이블)에 기준을 삼을 컬럼을 정한다. RIGHT 구문은 잘 사용하지 않는다.


SELF JOIN(같은 테이블 안에서 행과 행의 관계가 있는 경우, 그걸 연결해서 보고 싶을 때 셀프 조인을 할 수 있다.)

2. DML (Data Manipulation Language)은 데이터베이스에 저장된 데이터를 조회하거나 변경하는 데 사용하는 SQL 명령어
INSERT, UPDATE, DELETE, SELECT(DQL)

- INSERT
새로운 행을 추가하는 구문이다.
INSERT하고 싶은 데이터 컬럼을 지정도, 한번에 여러 행 추가도 가능하다.
INSERT INTO / VALUES

- UPDATE
테이블에 이미 존재하는 행의 컬럼 값을 수정
UPDATE/SET/WHERE
SET : 바꿀 내용
WHERE : 바꿀 대상

- DELETE
테이블에서 특정 행을 삭제하는 구문
DELETE FROM/WHERE

- REPLACE
INSERT시 PRIMARY KEY 또는 UNIQUE KEY가 충돌이 발생할 수 있다면
REPLACE를 통해 중복 된 데이터를 덮어 쓸 수 있다.
REPLACE INTO/VALUES

- Transaction (트랜잭션) - ALL or Nothing 모두 성공하거나, 모두 실패해야 하는 하나의 작업 단위
MYSQL은 기본적으로 autocommit 모드가 켜져있다. 조절하고 싶다면 설정을 바꿔줘야한다.
SET autocommit = OFF;

START TRANSACTION; 트랜잭션을 시작

트랜잭션 시작 전의 상태로 되돌린다. 커밋을 한 이후에는 소용없다.
ROLLBACK

작업이 올바르다고 판단되면 최종 저장 명령한다.
COMMIT
