컨테이너 시작 -> Bean 생성 -> 초기화 메서드 -> Bean 사용

컨테이너 종료 -> 소멸 메서드

@Bean(initMethod = "", destroyMethod = "") 
Bean이 생성 직후 initMethod = "" 큰 따옴표 안의 메서드 실행.
Container 종료 전 destroyMethod = "" 큰 따옴표 안의 메서드 실행.

초기화 시점과 종료에 맞춰 해야할 작업이 있을 때 사용한다.
특히 외부라이브러리 오픈소스를 수정할 수 없는 경우에 이러한 초기화 소멸 메서드를 활용할 수 있다.

엄밀하게 말하면 메서드가 아니라 속성 지정이라고 한다. initMethod라는 속성에 값을 속성 값을 지정하는 것.

build: 작성한 소스코드를 실행할 수 있게 준비하는 과정.
classpath: Java와 Spring이 실행 중에 파일을 찾는 범위.

@PropertySource(value=""): 설정 클래스에서 사용할 외부 설정 파일을 spring 환경에 등록.

@Value(): @Value가 properties의 문자열 값을 찾아 필드 타입에 맞게 변환하여 주입.
