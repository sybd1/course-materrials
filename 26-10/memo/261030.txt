- Rest API

HTTP (HyperText Transfer Protocol)
HTTP는 클라이언트(브라우저, 앱, 리액트 등)와 서버(스프링 등)가 데이터를 주고받기 위해 사용하는 통신 규칙(프로토콜)이다.
인터넷에서 웹페이지, 이미지, API 호출 등이 이루어지는 모든 방식이 HTTP 기반으로 이루어진다.

		HTTP Requerst
클라이언트 ----------> 서버
클라이언트 <---------- 서버
		HTTP Response

특징
비연결성(Coneectionless): 요청이 끝나면 서버는 클라이언트 정보를 유지하지 않는다. 요즘은 일부로 연결을 하는 상태도 있다.
무상태성(Stateless): 요청 간에 서버가 상태를 기억하지 않는다. 두번째 요청에서 첫번째 상태를 기억하고 있지 않다.
% 그래서 쿠키 세션 토큰 같은 기술이 필요하다.
텍스트 기반 프로토콜: 사람이 읽어도 이해할 수 있는 구조로 되어 있다.

HTTP 요청
GET, POST, PUT, PATCH, DELETE

Headers 요청
Content-Type: application/json 요청에 본문을 담는다.
Authorization: ?

Body 요청
실제 데이터. 주로 POST, PUT, PATCH 요청에 주로 사용됨.
예(JSON):
{
	"name": "설윤아",
	"age": 23
}

HTTP 상태코드
1xx: 정보
2xx: 성공/ 200 OK 요청성공, 201 CREATED 리소스 생성 성공, 204 No Content
3xx: 리다이렉트
4xx: 클라이언트 오류: 400 Bad Request, 401 Unauthorized(로그인 필요), 403 Forbidden(권한없음), 404 Not Found (리소스 없음)
5xx: 서버 오류: 500 Internal Server Error(서버 내부 오류/ 개발자 실수 가능성 높음)
