ai 모델이 저장되어 있는 곳은 클라우드인가? 
클라우드 데이터센터: 회사가 직접 소유하거나, 클라우드 사업자로부터 빌릴 수 있는 서버.
개인PC나 회사 내부 서버: Ai 모델을 저장장치에 저장하고, GPU, RAM을 통해 추론 계산할 수 있다.


모델의 사용량이 전세계적으로 늘어나면 ai 자체가 느려질 수 밖에 없나?
동시 요청 증가 -> 요청 대기시간 증가
GPU 자원 부족 -> 답변 생성 속도 저하
네트워크 혼잡 -> 요청,응답 지연

응답이 느린 것과 답변의 품질이 떨어지는 것은 서로 다른 문제다. 서버가 바쁘다고 모델이 반드시 덜 정확하게 답하는 것은 아니지만, 서비스가 혼잡할 때 다른 모델로 전환하거나 추론 설정을 바꾸면 답변 품질에도 차이가 생길 수 있다.

ai 성능에 일관성이 없다면, 자체 서버 자체 ai가 필요하다. 어떻게 만듬?
1. 자체 서버에서 외부 API를 사용하며 비용을 지불하거나, 공개 모델을 다운 받아 활용한다.
2. 처음부터 직접 모델을 학습시켜 Ai를 만드는 방법은 데이터, GPU, 전문인력 등 비용이 많이 발생한다. 기존 모델을 직접 학습하거나 미세조정을 하는 방법이 1인 개발자에겐 경제적이다. 

모델들은 각각 다른 클라우드 서버에 저장되어 있나?
실제 기업마다 다르다. 서버 하나에 여러 모델이 들어 있을 수 있고, 백업용 서버가 있을 수 있다. 추론 계산할 수 있는 하드웨어에 따라서 달라지고, 현재 회사의 상황에 따라서 달라진다.

클라우드 서버의 용량은 어느정도 되는가? 
SSD: 모델 파일과 데이터를 보관.
RAM: 운영체제와 프로그램이 사용하는 작업 공간.
GPU: Ai 모델의 계산에 필요한 가중치와 중간 결과 등을 보관.
알 수 없다. 굉장히 크다.

현재 사용되는 데이터 평균 사용량과 에너지 사용량의 비율은 어느정도 되는가?
에너지 사용량은 모델의 크기와 구조, 답변 길이, 추론 모드, 하드웨어 효율, 서버 활용률 등에 영향을 받는다.
입력 토큰 1000개, 출력 토큰 1000개 중간 길이 프롬프트 기준, 모델 별로 5~6Wh, 22~23Wh로 추정되고, 특정 모델별로 사용하는 에너지 사용량이 상이하다.

가중치?
AI에서 가중치(Weight)는 모델이 학습을 통해 얻은 숫자야. 이 숫자들이 입력 정보를 얼마나 중요하게 반영할지, 그리고 입력을 어떻게 조합해 결과를 낼지 결정하는 데 사용한다.

1. 초기화: 가중치를 초기 숫자로 설정해.
2. 예측: 입력 데이터를 이용해 결과를 계산해.
3. 오차 계산: 예측 결과와 정답이 얼마나 다른지 측정해.
4. 가중치 조정: 오차를 줄이는 방향으로 가중치를 조금씩 변경해.
5. 반복 학습: 이 과정을 반복하면서 데이터의 패턴을 학습해.
이 과정에서 가중치를 조정하는 데 사용되는 핵심 개념이 바로 **미분, 기울기(Gradient), 경사하강법(Gradient Descent)**이야. 나중에 AI를 공부할 때 선형대수학과 함께 배우게 될 중요한 개념
