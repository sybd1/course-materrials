어트리뷰트(Attribute)와 프로퍼티(Property)

1. 어트리뷰트 기본 조작

    HTML 태그에 부여된 속성(attribute)들을 자바스크립트로 읽고, 쓰고, 확인하고, 지우는 방법입니다.
    getAttribute / setAttribute 메서드를 사용하는 것이 가장 명확합니다.

2. input의 value 어트리뷰트와 value 프로퍼티

    어트리뷰트와 프로퍼티의 관계는 항목마다 다릅니다.
    여기서는 사용자가 입력한 현재값과 초기 설정값이 구분되는 input의 value를 비교합니다.
    - value 어트리뷰트: HTML에 설정한 기본값을 나타냅니다.
    - value 프로퍼티: 사용자가 편집한 현재 입력값을 나타냅니다.

3. 실무 활용: data 어트리뷰트와 dataset 프로퍼티

    HTML 표준 속성 외에, 화면 동작에 필요한 사용자 정의 데이터를 요소와 함께 저장할 때 사용합니다.
    data 어트리뷰트는 DOM에서 확인할 수 있으므로 비공개 데이터나 보안 저장소는 아닙니다.
    data-이름 형태로 HTML에 어트리뷰트를 작성하고,
    자바스크립트에서는 .dataset.이름 프로퍼티로 쉽게 접근할 수 있습니다.
