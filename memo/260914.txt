5. 05_attribute-and-property
HTML 요소의 attribute(속성) type, id, value
DOM 객체의 속성은 property

- attribute 기본 조작 방법
읽기: getAttribute('어트리뷰트이름') / 값이 존재하지 않으면 'null'을 반환한다.
쓰기: setAttribute('어트리뷰트이름', '새로운값')
확인: hasAttribute('어트이뷰트이름')
삭제: removeAttribute('어트리뷰트이름')

value attribute: HTML 마크업 텍스트 문서에 직접 작성된 초깃값(Deafalf Value). 사용자가 화면에서 글자를 입력하고 지워도 절대 변하지 않고 고정된다.
value property: 브라우저 메모리에 파싱되어 올라간 DOM 객체의 '현재 실시간 값(Current Value)'
